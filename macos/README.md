# 极载 · ZEELoad for macOS

SwiftUI 图形界面沿用项目的 macOS 脚本和 addon。适用于运行 macOS 13 及更新版本的 Apple 芯片 Mac。

## 构建并打开

1. 在 GitHub 打开 **Actions → Build ZEELoad for Apple Silicon → Run workflow**。
2. 构建完成后，在本次运行的 **Artifacts** 下载 `ZEELoad-macOS-arm64.zip`。
3. 解压后打开 `ZEELoad.app`。构建使用临时代码签名，并内置 Apple 芯片版 mitmdump 12.3.1。

## 使用

1. 在 **系统设置 → 通用 → 共享 → 互联网共享** 中选择 Mac 的上网来源，再共享到 Wi-Fi。车机连接这个 Wi-Fi。
2. 点击 **检查**。界面分别显示共享桥、车机 IPv4、Mac 默认路由和内置 `mitmdump` 的版本。自检和侧载都使用 App 内的 `mitmdump`，首次打开新版时会清除旧版保存的代理路径。
3. 拖入 APK 或点击 **选择 APK**，再点击 **开始侧载**。在 macOS 弹窗中授权。
4. 界面显示 **代理已监听** 后，在车机应用商店打开应用详情页。看到 **已识别更新** 后再在车机点更新。传输状态来自代理日志，安装结果以车机显示为准。
5. 车机确认安装后点击 **停止**。会话退出后会核验 GUI 专用的转发规则。需要单独清理规则时，可以点击 **恢复转发规则**。

## 车上没有网线

可先让 Mac 通过 iPhone USB 个人热点上网。如果 **互联网共享** 可以选择 `iPhone USB`，将该服务共享到 Wi-Fi，再让车机连接。开启共享后点 **检查**，分别确认 Mac 有默认路由和共享桥。若共享桥已出现但车机 IPv4 未识别，查看车机当前 Wi-Fi 的 IPv4 地址并填入 **高级设置**。

## 日志与恢复

- **日志目录** 打开 `~/Library/Logs/ZEELoad`。每次会话的 `activity.log` 保存运行输出，结束后归档底层日志。日志可能含车机网络与应用商店请求信息。
- 正常停止、关闭窗口或应用退出后，后台会话会清理自身规则。恢复按钮只处理 GUI 的 `com.apple/zeekr-capture-gui` anchor。旧命令行版仍运行时，先用原来的方式结束其会话。
- 车机使用你自己的共享网络。若规则清空后车机仍未恢复联网，可关闭并重新开启 Mac 互联网共享，再重新连接车机 Wi-Fi。
